# Touchbox

[English version](README_EN.md)

Touchbox — полноценный офлайн-плеер для локальной медиатеки iPod touch. Он объединяет функциональность современного локального музыкального плеера с отдельным Classic Mode, вдохновлённым iPod Classic и управляемым виртуальным Click Wheel.

Приложение создано прежде всего для iPod touch 3G с iOS 4.1. Возможен запуск на iOS 5 и iOS 6, однако основной целевой платформой и устройством для проверки остаётся iPod3,1 / iOS 4.1.

## Основные возможности

- Полноценное воспроизведение локальной медиатеки iPod/iOS.
- Просмотр библиотеки по альбомам, артистам и песням.
- Обложки альбомов и отдельный экран каждого релиза.
- Просмотр треков альбома с номером, названием и длительностью.
- Корректный порядок треков с учётом номера диска и трека.
- Автоматический переход на Now Playing после запуска песни.
- Mini-player в Standard Mode.
- Поиск, Favorites, собственные плейлисты, Recent и управляемая очередь.
- Два независимых интерфейса: Standard Mode и Classic Mode.
- Глобальные Light и Dark Theme.

## Now Playing

Полноценный экран текущего воспроизведения показывает:

- обложку;
- название песни;
- артиста и альбом;
- прогресс;
- прошедшее и оставшееся время;
- Play/Pause, Previous и Next;
- Shuffle и Repeat;
- Favorite;
- Queue;
- Add to Playlist.

Позицию можно менять ползунком, в том числе во время паузы. При смене трека метаданные, обложка, прогресс и состояние Favorite обновляются автоматически.

## Навигация и поиск

Для больших коллекций предусмотрены:

- алфавитная навигация A–Z/# в Artists;
- отдельная алфавитная полоса в Albums, не перекрывающая обложки;
- глобальный поиск по Songs, Albums, Artists, Favorites и Playlists;
- поиск по названию песни, артисту и альбому;
- сохранение правильного контекста очереди при запуске результата поиска.

Поиск использует уже построенный индекс и не сканирует системную медиатеку заново после каждого введённого символа.

## Favorites

Touchbox имеет собственную систему избранного, не зависящую от системных плейлистов. Можно:

- добавить или удалить текущую песню кнопкой-звездой;
- видеть состояние Favorite в списках и на Now Playing;
- открыть отдельный список Favorites;
- воспроизводить его как самостоятельную очередь;
- перемешать всё избранное;
- изменить Favorite через контекстное меню.

Избранное сохраняется между запусками приложения.

## Touchbox Playlists

Touchbox позволяет создавать собственные локальные плейлисты независимо от ограничений старого MediaPlayer API:

- создать плейлист и задать ему название;
- открыть, воспроизвести или перемешать его;
- добавлять и удалять песни;
- создать плейлист прямо во время прослушивания;
- добавить текущую песню с Now Playing;
- добавить песню через long press;
- избежать случайных дубликатов.

Также можно просматривать и воспроизводить системные iPod/iTunes playlists. Touchbox Playlists хранятся отдельно и не пытаются изменять системные плейлисты.

## Полноценная очередь

Touchbox поддерживает собственную модель playback queue:

- просмотр текущей очереди;
- переход к любой песне;
- Play Next;
- Add to Queue;
- Shuffle;
- сохранение и восстановление очереди после перезапуска.

Очередь учитывает контекст запуска. Если песня выбрана из альбома, очередь состоит из этого альбома; из плейлиста — из этого плейлиста; из Favorites, Recent или результатов поиска — из соответствующего списка.

## Контекстные действия

Long press по песне открывает доступные действия:

```text
Play Next
Add to Queue
Add to Playlist
Add/Remove Favorite
Go to Album
Go to Artist
```

Меню доступно в разных разделах приложения и работает с правильным треком даже в отфильтрованных результатах поиска. Обычный tap запускает песню и открывает Now Playing.

## Shuffle

Через общую playback-систему можно перемешать:

- всю медиатеку;
- отдельный альбом;
- все песни артиста;
- Favorites;
- Touchbox Playlist;
- Recently Played;
- Recently Added.

Исходный порядок библиотеки, альбома или плейлиста не меняется — перемешивается только очередь воспроизведения.

## Recent

Раздел Recent состоит из двух списков:

- **Recently Played** — история последних уникальных прослушанных песен;
- **Recently Added** — музыка, недавно обнаруженная индексом Touchbox.

Если старый публичный iOS API не предоставляет надёжную дату добавления, Touchbox использует собственное время первого обнаружения трека. Оба списка можно воспроизводить как очередь или перемешивать.

## Восстановление состояния

Touchbox запоминает:

- текущую песню;
- позицию внутри песни;
- очередь и текущий индекс;
- Shuffle и Repeat;
- последний UI mode;
- выбранную тему.

После перезапуска можно практически продолжить с прежнего места. Для предсказуемого запуска восстановленный player остаётся на паузе. Если часть музыки была удалена, недоступные треки пропускаются без падения приложения.

## Standard Mode

Standard Mode — обычный сенсорный интерфейс с tab bar, поиском, списками, mini-player и полноценным Now Playing.

Albums отображаются сеткой по две обложки в строке. В Standard Mode альбомы организованы прежде всего по исполнителю: Artist → Albums. Экран альбома показывает artwork, метаданные, Play и список треков.

Основные разделы:

- Albums;
- Artists;
- Songs;
- Favorites;
- Playlists.

## Classic Mode и виртуальный Click Wheel

Classic Mode — не просто визуальная тема, а отдельный интерфейс с собственной навигацией и настоящим круговым управлением пальцем:

```text
             MENU

       Previous     Next

            SELECT

           Play/Pause
```

Click Wheel поддерживает вращение по и против часовой стрелки, Center/Select, MENU/Back, Previous, Next и Play/Pause. Через него доступны:

- Music;
- Artists;
- Albums;
- Songs;
- Favorites;
- Playlists;
- Recent;
- Queue;
- Now Playing;
- Settings.

Classic Albums специально адаптирован для колеса: это плоский A–Z список по названию альбома, а не группировка Standard Mode по артистам.

Classic Now Playing показывает artwork, название, артиста, альбом, прогресс, время и позицию в очереди. Через Center доступны Favorite, Add to Playlist, Play Next, Queue, Shuffle и Repeat.

Standard и Classic используют одну медиатеку, одну очередь и один playback engine. Между ними можно переключаться прямо во время воспроизведения — музыка, позиция и очередь не сбрасываются.

## Light и Dark Theme

Глобальная тема работает в обоих интерфейсах, поэтому доступны четыре комбинации:

```text
Standard Light
Standard Dark
Classic Light
Classic Dark
```

Тема меняется на лету без перезапуска приложения и остановки музыки. Dark Mode использует отдельную графитовую палитру, включая адаптированные Standard UI, Classic display и Click Wheel, а не простую инверсию цветов. Выбор сохраняется между запусками.

## Оптимизация для старого железа

Touchbox рассчитан на iPod touch 3G примерно с 256 МБ RAM:

- библиотека индексируется одним проходом;
- lightweight persistent cache ускоряет повторный запуск Albums и Artists;
- artwork загружается лениво только для видимых элементов;
- in-memory artwork cache ограничен;
- изображения не сохраняются в индексе;
- таблицы используют reusable cells;
- Favorites, Playlists, Recent и Queue хранят persistent ID;
- поиск не выполняет новый `MPMediaQuery` на каждую букву;
- Click Wheel не обращается к медиатеке на каждом шаге;
- Classic Mode использует преимущественно лёгкие текстовые списки;
- тяжёлые эффекты и лишние анимации отсутствуют.

Цель проекта — не просто запускаться на iOS 4.1, а оставаться быстрым и пригодным для реального использования на его железе.

## Отличия от стандартного Music в iOS 4

Touchbox добавляет поверх локальной системной медиатеки:

**два интерфейса → виртуальный Click Wheel → Dark Mode → собственные Favorites → редактируемые Touchbox Playlists → Add to Playlist с Now Playing → Play Next → Add to Queue → управляемую очередь → поиск → Recent → восстановление playback state → расширенный Shuffle → контекстные действия → оптимизированный индекс библиотеки.**

При этом Touchbox остаётся нативным офлайн-плеером для музыки, которая уже находится на устройстве: без стриминга, аккаунтов, рекомендаций, рекламы и зависимости от интернета.

## Совместимость и установка

- основная платформа: iPod touch 3G / iPod3,1;
- проверенная целевая версия: iOS 4.1;
- возможен запуск на iOS 5 и iOS 6;
- экран 320×480, non-Retina;
- ARMv7;
- jailbreak и установка `.deb`;
- публичный `MediaPlayer.framework`.

После установки выполните respring. Если SpringBoard показывает старую или отсутствующую иконку, обновите icon cache через `uicache` и повторите respring.

> iOS 5 и iOS 6 указаны как возможная совместимость. Главная конфигурация разработки и device-тестов — iPod3,1 с iOS 4.1.

## Кратко о реализации

Проект написан на Objective-C с Manual Reference Counting и собирается Theos против `iPhoneOS4.1.sdk`:

```sh
make clean package THEOS=/path/to/theos
```

`TBLibraryManager` обслуживает индекс медиатеки, `TBPlayerManager` — общий playback и очередь, а Favorites, Playlists и Recent используют отдельные lightweight managers. `TBTheme` предоставляет общую палитру. Standard и Classic являются двумя presentation layers над одним playback engine и общими пользовательскими данными.
