# Touchbox

Touchbox — музыкальный плеер для iPod touch 3G и iOS 4.1. Он сочетает полноценный обычный интерфейс с отдельным Classic Mode, управляемым виртуальным Click Wheel.

Оба режима используют одну медиатеку, очередь и состояние воспроизведения. Музыку можно запустить в Standard Mode, перейти в Classic Mode и продолжить с того же места без сброса трека или очереди.

## Возможности

### Музыкальная библиотека

- Просмотр всех песен, альбомов и исполнителей.
- Albums в Standard Mode сгруппированы по исполнителю: Artist → Albums.
- Albums в Classic Mode представлены единым алфавитным списком по названию альбома.
- Экран альбома показывает обложку, исполнителя, список треков, их номера и длительность.
- Треки альбома воспроизводятся в правильном порядке с учётом номера диска и трека.
- Быстрая навигация A–Z/# в Albums и Artists.
- Поиск по песням, альбомам, исполнителям, избранному и плейлистам.
- Поиск выполняется по уже загруженной библиотеке и не запускает новый системный запрос на каждый символ.

### Воспроизведение

- Play/Pause, Previous и Next.
- Перемотка трека с отображением прошедшего и оставшегося времени.
- Shuffle для Songs, Album, Artist, Favorites, Playlist и Recent.
- Repeat One.
- Автоматический переход на Now Playing после выбора песни.
- Очередь соответствует месту запуска музыки: альбому, результатам поиска, избранному, плейлисту или недавним трекам.
- Содержимое очереди можно просматривать и выбирать вручную.
- Действия Play Next и Add to Queue.
- После перезапуска восстанавливаются очередь, текущий трек, позиция, Shuffle и Repeat. Для безопасного запуска воспроизведение остаётся на паузе.

### Now Playing

- Обложка текущего альбома.
- Название трека, исполнитель и альбом.
- Прогресс и перемотка.
- Play/Pause, Previous и Next.
- Shuffle и Repeat.
- Добавление и удаление текущего трека из Favorites.
- Добавление текущего трека в Touchbox Playlist.
- Переход к текущей очереди.

### Favorites

- Любой трек можно добавить в Favorites через кнопку-звезду.
- Избранное доступно как отдельный список и формирует собственную очередь.
- Favorites можно перемешать без изменения порядка сохранённых треков.
- Состояние избранного сохраняется после перезапуска.

### Плейлисты

- Просмотр и воспроизведение системных iPod/iTunes playlists.
- Создание собственных Touchbox Playlists.
- Добавление текущего трека в плейлист с Now Playing или из контекстного меню.
- Защита от добавления дубликатов.
- Удаление треков из Touchbox Playlist.
- Touchbox Playlists хранятся независимо от системных плейлистов и сохраняются после перезапуска.

### Recent

- Recently Played — до 200 последних уникальных треков.
- Recently Added — треки, впервые замеченные индексом Touchbox.
- Оба списка можно воспроизводить как отдельную очередь или перемешивать.

### Контекстные действия

Долгое нажатие на трек в Standard Mode открывает доступные действия:

- Play Next;
- Add to Queue;
- Add to Playlist;
- Add/Remove Favorites;
- Go to Album;
- Go to Artist.

Обычное короткое нажатие продолжает запускать трек и открывать Now Playing.

## Standard Mode

Standard Mode — основной сенсорный интерфейс Touchbox. Он содержит вкладки:

- Albums;
- Artists;
- Songs;
- Favorites;
- Playlists.

Albums отображаются сеткой по две обложки в строке. Artwork загружается постепенно только для видимых элементов, поэтому открытие большой библиотеки не требует предварительной загрузки всех изображений.

## Classic Mode

Classic Mode превращает экран iPod touch в интерфейс, вдохновлённый классическими iPod.

Верхняя часть экрана используется как компактный дисплей, нижняя — как виртуальный Click Wheel. Колесо поддерживает:

- вращение по и против часовой стрелки;
- Center/Select;
- MENU/Back;
- Previous;
- Next;
- Play/Pause.

В Classic Mode доступны:

- Music → Artists, Albums, Songs, Playlists и Favorites;
- Favorites;
- Recent;
- Queue;
- Now Playing;
- Settings.

Выбор трека формирует очередь текущего списка и открывает Classic Now Playing. Center на Now Playing открывает действия Favorite, Add to Playlist, Play Next, Queue, Shuffle и Repeat.

MENU возвращает на предыдущий Classic-экран. В Settings можно вернуться в Standard Mode. Переключение режима не прерывает музыку.

## Light и Dark Theme

Touchbox поддерживает две глобальные темы:

- Light — сохраняет светлый классический вид приложения;
- Dark — спокойная графитовая тема с фирменным синим акцентом.

Тема действует одновременно на Standard и Classic Mode и сохраняется после перезапуска. Её можно менять без остановки музыки, сброса очереди или закрытия текущего экрана.

В Standard Mode настройка находится в `Albums → Recent → Theme`, в Classic Mode — в `Settings → Theme`.

## Производительность

Touchbox рассчитан на iPod touch 3G с 256 MB RAM:

- библиотека индексируется одним проходом;
- Albums и Artists используют лёгкий persistent cache;
- сохранённый индекс загружается сразу после запуска;
- artwork загружается только по требованию;
- thumbnail cache ограничен по размеру;
- изображения не сохраняются внутри индекса библиотеки;
- reusable cells не удерживают обложки всей медиатеки;
- поиск, Click Wheel и работа с очередью не запускают повторное сканирование библиотеки.

## Установка

Установите собранный `.deb` на совместимое устройство обычным способом для jailbroken iOS, затем выполните respring. Если SpringBoard продолжает показывать старую или пустую иконку, обновите icon cache через `uicache` и повторите respring.

Данные Touchbox — Favorites, playlists, Recent, тема и очередь — сохраняются в пользовательском Library/sandbox и не содержат artwork или сериализованных `MPMediaItem`.

## Совместимость

- iPod touch 3G / iPod3,1;
- iOS 4.1;
- экран 320×480, non-Retina;
- ARMv7;
- публичный `MediaPlayer.framework`.

Основной целевой сценарий проверяется на настоящем iPod touch 3G. Современные iOS API и private frameworks не используются.

## Техническая информация

Проект написан на Objective-C с Manual Reference Counting и собирается через Theos против `iPhoneOS4.1.sdk`:

```sh
make clean package THEOS=/path/to/theos
```

Ключевые компоненты:

- `TBLibraryManager` — загрузка и лёгкий индекс медиатеки;
- `TBPlayerManager` — общий player, очередь и сохранение playback state;
- `TBFavoritesManager`, `TBUserPlaylistManager`, `TBRecentManager` — пользовательские данные;
- `TBTheme` — глобальная Light/Dark palette;
- `TBClassicViewController` и `TBClickWheelView` — Classic presentation и управление.

Standard и Classic являются двумя presentation layers над общими managers. В проекте нет отдельного playback engine для Classic Mode.
